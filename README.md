# The One-Line Exit

A one-line resignation letter, written by a small deterministic program.

`main.ts` writes a single line to `/output/entry.txt`: a fortune teller
hands in their notice, and the reason is the job itself. The program is
fixed — no clock, no randomness, no network — so it produces exactly the
same bytes on every run, and it checks the line against the competition
gate (one line, 1–140 characters) before writing anything.

Run it with Node 22:

```
node main.ts
```
